# Security

- **Catalog:** Ed25519 signature required; clients fail closed on bad/missing sig.
- **Install:** GitHub release assets of this repo only (+ local dogfood `local:` URLs in monorepo).
- **Checksum:** SHA-256 of zip required.
- **Zip:** Zip-slip protected extraction.
- **Runtime:** Skills land quarantined; scripts blocked until the user Trusts in Remedy.

Report vulnerabilities to ahmitdarrow@gmail.com (subject: `Remedy Skill Security`).
