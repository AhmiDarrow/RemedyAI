# Iconography Guide

## Steps
1. Style (outline/filled) and stroke weight.
2. Keyline grid for 16/24px.
3. Metaphor list to avoid collisions.
4. Contrast and labels for ambiguous icons.
5. Export checklist (SVG clean, viewBox).
