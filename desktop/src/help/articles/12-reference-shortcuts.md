# Keyboard shortcuts

Canonical list for Remedy Desktop. Also shown under **Settings → Help & shortcuts**.

## Composer

| Keys | Action |
|------|--------|
| **Enter** | Send message |
| **Shift+Enter** | Insert a new line |
| **Shift+Tab** | Toggle Plan / Build mode |
| **↑** | Previous prompt (when appropriate) |
| **↓** | Next prompt while browsing history |

## App-wide

| Keys | Action |
|------|--------|
| **Ctrl+N** | New chat session |
| **Ctrl+P** / **Ctrl+K** | Command palette |
| **Ctrl+B** | Toggle Plan / Build mode |
| **Ctrl+,** | Open Settings |
| **Ctrl+/** | Open Help wiki |
| **F1** | Open Help wiki |
| **Escape** | Close panels, Help, and command palette |

## Logo menu

Open from the title-bar wordmark: New session, Settings, Memory, Skills, Updates, Help, About, Quit.
