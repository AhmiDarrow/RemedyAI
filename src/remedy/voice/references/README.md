# Reference voices for the high-quality engine

Twelve-second speech samples the high-quality voice (Chatterbox) clones so
Remedy has a steady, human voice for each gender. Both recordings are in
the **public domain** (LibriVox volunteers release all recordings into the
public domain; the archive.org items carry the CC0 / public-domain mark).

| file | reader | source |
|------|--------|--------|
| `female.wav` | Karen Savage | *Pride and Prejudice* (Jane Austen), LibriVox — https://archive.org/details/pride_and_prejudice_librivox |
| `male.wav` | Stewart Wills | *Moby Dick* (Herman Melville), LibriVox — https://archive.org/details/moby_dick_librivox |

Trimmed to 12 s of continuous speech, 24 kHz mono 16-bit, peak-normalised.
An owner-provided reference (Settings → Voice) takes precedence for its
gender; these are the defaults.
