# Reference voices

Twelve-second speech samples Remedy's voice engine (Chatterbox Nano) clones,
one per gender. Both recordings are in the **public domain** (LibriVox
volunteers release all recordings into the public domain; the archive.org
items carry the public-domain mark).

| file | reader | source |
|------|--------|--------|
| `female.wav` | Kara Shallenberg | *The Secret Garden* (Frances Hodgson Burnett), LibriVox — https://archive.org/details/secret_garden_librivox |
| `male.wav` | Stewart Wills | *Moby Dick* (Herman Melville), LibriVox — https://archive.org/details/moby_dick_librivox |

Windows were chosen by measurement (steady pitch line, even loudness, an
unhurried rate, no long pauses), trimmed to 12 s, 24 kHz mono 16-bit,
peak-normalised. An owner-provided reference takes precedence for its
gender; the numeric identity (`remedy.voice.identity`) is applied on top.
