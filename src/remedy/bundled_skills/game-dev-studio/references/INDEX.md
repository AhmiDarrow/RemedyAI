# game-dev-studio references

- gdd-template.md — the 1–2 page GDD skeleton with the live cut list; copy it to docs/gdd.md in Phase 1.
- scope-and-milestones.md — milestone shapes, time estimates, what a finished slice looks like, when to cut.
- playtesting.md — full playtest protocol: scripted runs with game_playtest, owner sessions, what to log, how to rank findings.
- juice-and-feel.md — the feel-tuning order with starting numbers: latency, coyote/buffer, hit-stop, shake, squash, particles, camera.
- performance-budgets.md — per-platform fps/frame-time/memory/draw-call budgets and how to measure them in Godot.
- asset-conventions.md — naming, folder layout, atlas/import settings, pixel-perfect project settings.
- save-systems.md — safe save/load design (JSON + FileAccess), versioning, user:// paths, what never to do.
- input-maps.md — action naming, keyboard+gamepad defaults, deadzones, remapping UI, touch.
- audio.md — bus layout, SFX pooling, music loops, volume settings, formats and import flags.
