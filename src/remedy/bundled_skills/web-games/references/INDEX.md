# Web games references

- `phaser-scenes.md` — when writing Phaser 3 code: game config, scene
  lifecycle, input, arcade physics, animations, scene switching.
- `pixi-basics.md` — when the project uses PixiJS: Application, containers,
  sprites, ticker loop, asset loading, a minimal state pattern.
- `vite-setup.md` — when scaffolding or fixing build/dev config: scripts,
  `base`, public vs imported assets, TypeScript, ports.
- `testing-logic.md` — when adding tests: isolating logic from the engine,
  vitest config, jsdom, what not to test.
- `publishing-html5.md` — when exporting: `dist/`, static hosts, itch.io zip
  rules, viewport and fullscreen.
