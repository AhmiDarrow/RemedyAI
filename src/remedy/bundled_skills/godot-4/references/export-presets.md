# Export presets

## export_presets.cfg
Lives in the project root; created by Project → Export in the editor.
`godot_export` and `--export-release` need a preset **by name** from this
file. Minimal shape:
```ini
[preset.0]
name="Windows Desktop"
platform="Windows Desktop"
runnable=true
export_filter="all_resources"
include_filter=""
exclude_filter=""
export_path="build/win/game.exe"

[preset.0.options]
binary_format/embed_pck=true
```
Preset names with spaces must be quoted on the command line. `export_path`
is only a default; the CLI path wins. Create the output directory first.

## Templates
Exports need export templates matching the exact engine version
(`4.3.stable` ≠ `4.3.1.stable`). They live in the editor data dir
(`%APPDATA%/Godot/export_templates/<version>/` on Windows,
`~/.local/share/godot/export_templates/` on Linux, `~/Library/Application
Support/Godot/export_templates/` on macOS). Install from Editor → Manage
Export Templates or download the `.tpz` from godotengine.org and point the
dialog at it. You cannot install them without the owner; say so and ask.
Error text when missing: `No export template found at the expected path`.

## Commands
```text
godot --headless --path . --export-release "Windows Desktop" build/win/game.exe
godot --headless --path . --export-debug "Web" build/web/index.html
godot --headless --path . --export-pack "Windows Desktop" build/patch.pck
```
Exit code 0 and the file exists = success. Check file size: a tiny `.exe`
with no `.pck` beside it means the pck was neither embedded nor written.

## Per-platform notes
- **Windows**: `.exe` + `.pck` unless `embed_pck`. Code signing optional.
  A `*.console.exe` wrapper is for debugging only.
- **Linux**: `.x86_64`; mark executable in the archive. Case-sensitive
  filesystem: `res://Assets/hero.PNG` referenced as `assets/hero.png` loads
  on Windows and dies here.
- **macOS**: `.zip`/`.dmg`; unsigned builds trigger Gatekeeper; signing
  needs a Mac.
- **Web**: needs the Web template; the host must send
  `Cross-Origin-Opener-Policy: same-origin` and
  `Cross-Origin-Embedder-Policy: require-corp` (itch.io has a checkbox).
  Will not run from `file://`. C# is not supported on web in 4.x.
- **Android**: Java 17, Android SDK, keystore (debug keystore generated by
  the editor). Not a headless-only job on a fresh machine.
- **iOS**: exports an Xcode project; build on a Mac.

## Export filters
`export_filter="all_resources"` ships every imported resource; use
`exclude_filter="*.psd, tools/*, test/*"` to drop sources and tests.
Non-resource files (`.json`, `.txt`, `.csv`) must be listed in
`include_filter` or they are silently missing at runtime.
