# Project layout

```text
<project>/
  Assets/                 everything the game ships or edits
    Scripts/              runtime C# (optionally per-feature subfolders)
    Editor/               editor-only code (build scripts, inspectors)
    Tests/
      EditMode/           + EditMode.asmdef
      PlayMode/           + PlayMode.asmdef
    Scenes/  Prefabs/  Materials/  Art/  Audio/  Resources/  StreamingAssets/
  Packages/manifest.json  package dependencies (UPM)
  Packages/packages-lock.json
  ProjectSettings/        ProjectVersion.txt, InputManager, Tags/Layers, Physics
  Library/  Temp/  Logs/  obj/   generated; gitignored
  *.csproj, *.sln         generated by the editor; do not hand-edit
```

## Fingerprint facts

- `ProjectSettings/ProjectVersion.txt` → `m_EditorVersion` and
  `m_EditorVersionWithRevision`. Match the installed editor to it.
- `Packages/manifest.json` → `"dependencies"`: look for
  `com.unity.test-framework` (tests), `com.unity.inputsystem` (new input),
  `com.unity.render-pipelines.universal` (URP) vs HDRP vs built-in.
- `.meta` files: one per asset, hold the GUID. Never delete or regenerate
  by hand; moving an asset without its `.meta` breaks references.
- Any folder named `Editor` compiles into an editor-only assembly and is
  stripped from builds. Any folder named `Resources` is loadable at runtime
  via `Resources.Load`; keep it small.
- `Plugins/` for native DLLs and third-party managed DLLs.

## Where new things go

| Thing | Place |
|-------|-------|
| gameplay script | `Assets/Scripts/<Feature>/Name.cs` |
| data definition | `ScriptableObject` class in `Scripts/`, instances as `.asset` in `Assets/Data/` |
| build/CI helper | `Assets/Editor/` |
| logic tests | `Assets/Tests/EditMode/` |
| behaviour tests | `Assets/Tests/PlayMode/` |

## Assembly definitions (asmdef)

Without any asmdef everything is `Assembly-CSharp` (runtime) and
`Assembly-CSharp-Editor`. Test assemblies cannot reference
`Assembly-CSharp`, so code under test needs its own asmdef (or tests live
in the same assembly). Large projects split per feature to cut recompile
time. An asmdef is a small JSON file next to the code — see `test-runner.md`.

## Git hygiene

`.gitignore` should drop `Library/`, `Temp/`, `Logs/`, `obj/`, `Build*/`,
`*.csproj`, `*.sln`, `UserSettings/`. Force-text serialization is the
default for new projects, which keeps scenes and prefabs diffable.
