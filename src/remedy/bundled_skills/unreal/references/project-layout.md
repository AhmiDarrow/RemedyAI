# Project layout

```text
<Name>/
  <Name>.uproject          JSON manifest (see below)
  Source/
    <Name>.Target.cs       game target
    <Name>Editor.Target.cs editor target
    <Name>/
      <Name>.Build.cs      module deps (PublicDependencyModuleNames …)
      <Name>.h / .cpp      module entry (IMPLEMENT_PRIMARY_GAME_MODULE)
      Public/ Private/     headers/impls (optional convention)
  Content/                 .uasset / .umap — binary, editor-only
  Config/                  DefaultEngine.ini, DefaultGame.ini, DefaultInput.ini
  Plugins/                 project plugins (*.uplugin + Source/ + Content/)
  Binaries/ Intermediate/ Saved/ DerivedDataCache/   generated; gitignore
  .vs/ *.sln               generated by UBT
```

## .uproject fields

```json
{
  "FileVersion": 3,
  "EngineAssociation": "5.4",
  "Category": "",
  "Description": "",
  "Modules": [
    { "Name": "MyGame", "Type": "Runtime", "LoadingPhase": "Default" }
  ],
  "Plugins": [ { "Name": "EnhancedInput", "Enabled": true } ]
}
```

- `EngineAssociation`: `"5.x"` ⇒ Launcher install under
  `%PROGRAMFILES%\Epic Games\UE_5.x`; a `{GUID}` ⇒ a source build
  registered in the registry / `~/.config/Epic/UnrealEngine/Install.ini`;
  empty ⇒ the engine that opens it.
- No `Modules` ⇒ Blueprint-only project; adding one C++ class turns it into
  a C++ project (and requires a compiler).

## Build.cs essentials

```csharp
using UnrealBuildTool;
public class MyGame : ModuleRules
{
    public MyGame(ReadOnlyTargetRules Target) : base(Target)
    {
        PCHUsage = PCHUsageMode.UseExplicitOrSharedPCHs;
        PublicDependencyModuleNames.AddRange(new[] {
            "Core", "CoreUObject", "Engine", "InputCore", "EnhancedInput" });
        PrivateDependencyModuleNames.AddRange(new string[] { });
    }
}
```

Using a class from a module you did not list ⇒ unresolved external at
link time. Add the module here, not to the Target.cs.

## Config

- `DefaultEngine.ini`: `[/Script/EngineSettings.GameMapsSettings]`
  `GameDefaultMap`, `EditorStartupMap`, `GlobalDefaultGameMode`.
- `DefaultGame.ini`: project name, version, packaging settings
  (`+MapsToCook`).
- `DefaultInput.ini`: legacy action/axis mappings; Enhanced Input uses
  assets in `Content/` instead.

## What is text vs binary

Text (you edit): `.uproject`, `.uplugin`, `*.cs`, `*.h/.cpp`, `*.ini`,
`*.usf/.ush` shaders. Binary (editor only): `.uasset`, `.umap`, `.ubulk`.
Describe Blueprint/level changes for the owner; never patch binaries.

## Git hygiene

Ignore `Binaries/`, `Intermediate/`, `Saved/`, `DerivedDataCache/`, `.vs/`,
`*.sln`. Use Git LFS for `Content/**` binaries.
