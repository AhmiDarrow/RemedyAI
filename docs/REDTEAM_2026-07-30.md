## Threat model (unchanged honesty)

Same Windows user ≈ owner power. Loopback malware as your user is still the boundary. We harden **against lesser local processes, misconfig, and agent tool abuse** — not against full user compromise.

## Fixes landed this pass

### 1. S-AUTH-04 — Computer host Bearer (High → mitigated)

**Before:** Any same-user loopback client could `GET /api/computer/jobs/next` (steal/claim jobs), complete jobs, and drive ui/command without Bearer.

**After:**
- Middleware requires Bearer for `/api/computer/host|jobs|ui/*`.
- `/api/computer/a11y/*` remains loopback-only + `job_id` secret (legacy inject).
- Rust poller loads DPAPI `local_api_token` (cached 30s) and sends `Authorization`.
- SPA `hostFetch` already sent auth; comment updated.
- Test: `test_computer_host_routes_require_bearer`.

**Capability preserved:** Desktop + SPA still claim at full speed once token exists; poller waits briefly for token file after API ping.

### 2. Shell write jail — global package managers

**Before:** `npm install -g …`, `cargo install`, `yarn global add`, etc. allowed when cwd was under project (no path tokens → “cwd OK”).

**After:** Treated as opaque mutations; local `npm install lodash` still allowed under project cwd.
